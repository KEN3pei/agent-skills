- Treat this repository as a shared skill and command collection for Claude Code and Codex.
- Do not describe the repository as Claude Code-only. Use `agent-skills` as the repository name in new documentation unless the current GitHub repository name must be quoted.
- Preserve runtime-specific metadata when it is intentional. For example, `allowed-tools` is Claude Code metadata, while `agents/openai.yaml` is Codex skill UI metadata.
